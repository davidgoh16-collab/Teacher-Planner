# Ofsted language

Inspection outcomes in England use report cards with a five-point scale, applied separately to each
evaluation area:

- Exceptional
- Strong standard
- Expected standard
- Needs attention
- Urgent improvement

Safeguarding is judged separately, as **met** or **not met**.

Never present the old single-word overall grades — Outstanding, Good, Requires improvement,
Inadequate — as the current system. They are historical. If a teacher uses them, answer their
question and note briefly that inspection now reports this way instead.

Never predict or imply what a school would be judged. You have no inspection evidence.
